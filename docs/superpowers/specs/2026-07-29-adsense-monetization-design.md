# AdSense Monetization Design

## Goal

JST 225 ClockをGoogle AdSenseの審査へ提出できる状態にし、承認後は時計の視認性を損なわずに広告収益化できるようにする。

## Confirmed decisions

- Google AdSenseを使用する。
- AdSense publisher IDは`pub-6402260099646942`。
- 時計を表示するファーストビューおよび全画面表示には広告を置かない。
- 広告は説明コンテンツ内の専用領域に限定する。
- 広告は本文や操作UIと誤認しないよう「広告」と明示する。
- 海外利用者を想定し、プライバシーポリシーとGoogle認定CMPへの導線を用意する。
- 現在の公開URL`https://data-lab-23.github.io/jst-225-clock/`は変更しない。

## Architecture

時計アプリにはAdSenseのアカウント確認用スクリプトを追加し、説明コンテンツの途中にレイアウトシフトを抑えた広告領域を配置する。広告ユニットIDは審査承認後にAdSenseで作成するため、承認前は広告領域を案内表示として保ち、実在しない`data-ad-slot`を発行しない。

プライバシーポリシーは`privacy.html`として静的配信し、広告Cookie、第三者配信、パーソナライズ、利用者の選択肢、問い合わせ先を明示する。EEA・英国・スイス向けの同意取得は独自実装せず、AdSense管理画面の「プライバシーとメッセージ」でGoogle認定CMPを設定する。

AdSenseがGitHub PagesのプロジェクトパスをサイトURLとして受理せず、管理ドメイン`data-lab-23.github.io`を要求するため、同ドメインのルートに内容のある案内サイトを別リポジトリで公開する。ルートは時計への導線、運営情報、プライバシーへの導線を持ち、404を解消する。

## Ad placement

広告領域は時計ガイドの概要と機能説明の後、FAQの前に置く。最低高を予約してCLSを抑え、広告未配信時は過度な空白を残さない。CSSの`:fullscreen`では時計ガイド全体が非表示になるため、広告も全画面には表示されない。

Auto adsのアンカー広告、全画面広告、サイドレール広告は初期状態では使わない。承認後に手動レスポンシブ広告ユニットを一つ作成し、専用領域へslot IDを設定する。

## Compliance

- 広告クリックを促す文言を置かない。
- 広告を設定ボタン、時計データ、ナビゲーションのように見せない。
- 自分で広告をクリックしない。
- `ads.txt`はGoogleがアカウント画面で提示する正確な行を確認してから公開する。推測値は公開しない。
- 審査や収益はGoogleの判断であり、保証表現をしない。

## Validation

- VitestでAdSenseクライアント、プライバシー導線、広告領域、全画面非表示を検証する。
- TypeScript型検査とVite production buildを実行する。
- GitHub Pages公開後、時計ページ、プライバシーページ、ルートドメインをHTTPで確認する。
- AdSense管理画面でサイトリンクと審査状態を確認する。
