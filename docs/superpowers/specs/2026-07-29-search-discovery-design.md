# JST 225 Clock 検索流入改善設計

## 目的

JST 225 Clock を「日本標準時 時計」「現在時刻 日本」「JST 時計」「全画面 時計」などの日本語検索から発見できる状態にする。現在の時計を主役とする体験を維持しながら、検索エンジンと初めて訪れた利用者がページの用途を理解できる情報を追加する。

## 対象範囲

- 日本語検索を最優先し、英語の基本語句も自然に併記する。
- 現在の時計をファーストビューとして維持する。
- 時計の下に説明、特徴、使い方、日本標準時の解説、FAQを追加する。
- タイトル、description、canonical、OGP、SNS共有情報を整備する。
- `robots.txt` と `sitemap.xml` を公開する。
- `WebApplication` のJSON-LD構造化データを追加する。
- SEO要素の自動テストと公開後検証を追加する。

## 対象外

- 日経平均株価そのもの、金融情報、株価データの提供。
- 「日経」「日経平均」名称を検索流入目的で反復すること。
- 複数の時差・都市別ページを今回同時に作ること。
- 検索順位や訪問者数を保証すること。
- アクセス解析や広告ネットワークを無断で追加すること。

## ページ構成

### ファーストビュー

既存の時計ボードを維持する。PC・テレビでは可能な限り画面内に収め、時計を主役にする。既存の設定、全画面表示、タイムゾーン自動判定、市場更新風エフェクトは変更しない。

### 検索・利用者向け本文

時計の下へ次の順で配置する。

1. 「日本標準時を表示するオンライン時計」という一文の説明
2. 24時間表記、秒表示、タイムゾーン自動判定、全画面表示などの特徴
3. 日本標準時（JST）とUTC+9の簡潔な説明
4. PC、テレビ、スマートフォンでの使い方
5. よくある質問
6. 英語話者向けの短い補足
7. 非公式の時計アプリであり、株価情報を表示しないことの明記

「株価ボード風」「テレビの市況画面を思わせるデザイン」という説明を用い、公式サービスとの誤認を避ける。

## メタデータ

- title: `日本標準時の現在時刻｜秒まで見やすいJSTオンライン時計`
- description: 日本標準時の現在時刻を24時間表記・秒単位で確認でき、全画面表示にも対応する無料オンライン時計であることを簡潔に記載する。
- canonical: `https://data-lab-23.github.io/jst-225-clock/`
- `robots`: `index,follow`
- OGPとTwitter Cardには同じ内容と正式URLを指定する。
- `lang="ja"` を維持する。

## 構造化データ

HTML内へJSON-LDの `WebApplication` を記述する。名称、説明、URL、無料であること、ブラウザ対応、用途を、実際に画面で確認できる内容だけで表現する。レビュー、評価、ダウンロード数など存在しない情報は追加しない。

FAQ本文は画面に表示するが、検索結果での表示が限定されているためFAQ構造化データは今回追加しない。

## クロール

- `robots.txt` でサイトのクロールを許可し、サイトマップURLを案内する。
- `sitemap.xml` にはcanonical URLを1件掲載し、デプロイ日の `lastmod` を指定する。
- GitHub Pagesのプロジェクトパスでも正しく取得できるよう、Viteの `public` ディレクトリから静的配信する。

## 表示設計

- 説明部分は時計ボードと視覚的に分離し、濃紺背景と既存の青・白・赤を引き継ぐ。
- 時計ボードの幅を基準に本文を中央配置する。
- セクション見出しと本文は読みやすい一般的な文字サイズにする。
- モバイルでは一列、広い画面では特徴カードや補足を複数列にする。
- 全画面表示中は時計以外の本文を表示しない。
- `prefers-reduced-motion`、フォーカス表示、見出し階層を維持する。

## テストと公開検証

- HTMLに固有のtitle、description、canonical、OGP、JSON-LD、表示本文が含まれることを自動テストする。
- `robots.txt` と `sitemap.xml` のURLおよび構文を自動テストする。
- 既存の全テスト、型検査、本番ビルドを通す。
- PC、短いテレビ画面、スマートフォンで時計と本文の表示を確認する。
- 公開後にcanonical、robots、sitemap、構造化データ、コンソールエラーを確認する。

## 公開後の運用

Google Search Consoleへプロパティを登録できる場合は、サイトマップを送信し、URL検査からインデックス登録をリクエストする。検索順位は保証せず、表示回数、クリック数、検索クエリを見ながら将来の都市別・時差解説ページを判断する。
