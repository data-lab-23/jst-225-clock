# JST 225 Clock

JST 225 Clock は、日本標準時を中心に現在の時刻を見やすく表示するシンプルな時計アプリです。表示する時計の項目は、次の5項目です。

- 現在時刻
- 日付
- 曜日
- 秒
- タイムゾーン

## 開発

Node.js 24 を使用します。依存関係のインストール、開発サーバー、検証、ビルドは次のコマンドで実行できます。

```bash
npm install
npm run dev
npm test
npm run typecheck
npm run build
```

## 設定

設定画面では、文字サイズ、表示サイズ、パネル色、アクセント色、文字色を調整できます。変更した内容はブラウザのローカルストレージに保存され、次回の表示時にも復元されます。設定画面の「初期設定に戻す」で、すべての項目を既定値に戻せます。

タイムゾーンが `Asia/Tokyo` のときは、見出しに「日本標準時 / Japan Standard Time 225」を表示します。日本以外のタイムゾーンでは、自動的に「現地時間 / Local Time 225」へ切り替わります。

全画面表示はブラウザの Fullscreen API を利用します。この機能はユーザー操作から実行する必要があり、ブラウザの設定、埋め込み表示、対応状況によっては利用できない場合があります。

## GitHub Pages への公開

GitHub でリポジトリの **Settings → Pages** を開き、公開元に **GitHub Actions** を選択してください。`main` への push または手動実行で、テスト・型検査・ビルド後に Pages へ公開されます。

GitHub Pages のプロジェクトサイトは `/<リポジトリ名>/` 配下で配信されます。ワークフローはリポジトリ名から `VITE_BASE_PATH=/<リポジトリ名>/` を設定してビルドするため、配備先でもアセットのパスが正しく解決されます。ローカルで同じパスを確認する場合は、次のように実行します。

```bash
VITE_BASE_PATH=/jst-225-clock/ npm run build
```
