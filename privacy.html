プライバシーポリシー

JST 225 Clock（以下「本サイト」）における、利用者情報、広告、Cookie、 ブラウザ内への設定保存および外部サービスの取り扱いを説明します。

運営者

本サイトはdata-lab-23が運営する独立した時計Webアプリです。 お問い合わせは GitHub Issues から受け付けています。公開フォームには個人情報や機密情報を書き込まないでください。

ブラウザに保存する情報

配色や文字サイズなどの表示設定を維持するため、ブラウザのlocalStorageに設定値を保存します。 この設定値は利用者の端末内に保存され、本サイトのサーバーへ送信する目的では使用しません。 ブラウザのサイトデータを削除すると設定も削除されます。

Google AdSenseとCookie

本サイトは、第三者配信の広告サービスであるGoogle AdSenseを利用します。 Googleおよび第三者配信事業者は、Cookieや類似の技術を使用し、利用者の過去のアクセス情報に基づいて 広告を配信する場合があります。

Cookieの利用によりパーソナライズ広告が表示されることがあります。 地域、同意状況、アカウント設定などに応じて、非パーソナライズ広告または制限付き広告が 表示される場合もあります。

Googleによる情報の取り扱いは Googleプライバシーポリシー および Googleのサービスを使用するサイトやアプリから収集した情報の使用 をご確認ください。

広告に関する選択

Googleアカウントの広告設定は Google広告設定 から確認・変更できます。ブラウザの設定からCookieを削除または制限することもできますが、 一部の表示や同意設定が正しく保持されない場合があります。

欧州経済領域、英国、スイスなど、同意取得が必要な地域では、Google認定の同意管理機能を通じて 広告目的のデータ利用を選択できます。

アクセス情報

GitHub Pagesおよび広告配信事業者は、サービス提供、安全性の確保、不正利用の防止、 広告配信や測定のため、IPアドレス、ブラウザ情報、閲覧日時、参照元などの技術情報を 処理する場合があります。本サイト独自の会員登録機能はありません。

外部リンク

本サイトから移動した外部サイトでの情報の取り扱いは、各サイトのプライバシーポリシーに従います。 本サイトのポリシーは外部サイトには適用されません。

改定

利用する機能、法令、サービス要件の変更に応じて本ポリシーを改定することがあります。 重要な変更は本ページでお知らせします。
